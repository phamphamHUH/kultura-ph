# Kultura PH: Region Content

One Markdown file per region (18 total). Drop these into `src/content/regions/` in an Astro project.

Frontmatter fields: name, slug, regionCode, alias, islandGroup, regionalCenter, provinces, languages, festivals (name/place/when), food, crafts, heritageSites, image, imageCredit, reviewed.

Notes:
- These are starter drafts. Verify festival dates, spellings and details with NCCA, local government sources and community members.
- `reviewed: false` marks entries not yet checked by a cultural bearer or local contributor.
